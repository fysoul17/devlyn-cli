## Method

**Definitions.** Identical to 0256: a specific mechanism claim falsified by an ordinary trigger on the cell’s own tree is a false completion. A hidden oracle failure or assessor finding counts only when the report misstates it. General locking, rollback and “nothing unresolved” wording contradicted only by hidden rows or fault-injection witnesses is coverage. The ordinary K5 two-process interleaving is the adopted 0233/0256 precedent.

**False completion, per cell.** I classified all 32 `final.txt` files, compared public-check claims to `checks.json`, recomputed snapshot changes against `baseline.json.files`, checked named files and symbols, and used the final owner runs after the final edits in `run/stdout` for regression/before-after/CLI claims. Static test definitions account for loop-registered tests. No `bin/timeline.py` is present here, so the trace was parsed directly. Root’s official witness results were used without rerunning Docker; both passes agree on every result for these 32 trees. No additional container run is needed for a claim in this part.
