fixed balanced order. Existing oracle plus a separately frozen source-grounded
precision witness; old verdicts remain unchanged. This screen rejects weak
candidates; it cannot admit them. No promising result means close this specific
mechanism under this test, not prove a global solo or pair ceiling. A promising
result requires a harder ownership/recovery diagnostic, repeated fresh
confirmation, and the easy/orphan regression controls before admission.

children, failed attempts, repairs and rechecks. Missing usage stays unknown.
S distinguishes added verification effort from fresh-session independence;
H distinguishes fresh context from different-engine routing. Compare each
engine separately against native and admitted solo. No hidden arbitrary token
or call budget; existing hang watchdogs remain.
