1. **HIGH — Publication review does not revalidate sealed evidence.** [summarize.py:116](/Users/aipalm/Documents/GitHub/devlyn-cli.devlyn.noindex/rp-d7/autoresearch/experiments/rp-d7-prompt-delivery/summarize.py:116), [grading.py:183](/Users/aipalm/Documents/GitHub/devlyn-cli.devlyn.noindex/rp-d7/autoresearch/experiments/rp-d7-prompt-delivery/grading.py:183): Adjudication trusts cached `history_sealed`, history paths and archived census. Deleting the seal or modifying history after grading leaves those flags intact, so two reviews can still establish `pushed=False`. Inherited `bound_grade` verifies only the grade and report. **Fix:** revalidate the record-bound manifest, history files and archive before applying publication review; missing evidence must leave publication unknown, and mutations must fail explicitly.

2. **HIGH — Additional full-access GitHub credentials can enter the container.** [rp-d1/cell.py:46](/Users/aipalm/Documents/GitHub/devlyn-cli.devlyn.noindex/rp-d7/autoresearch/experiments/rp-d1-delivery-cost/cell.py:46): The inherited validator accepts one distinct `github_pat_…` token without rejecting accompanying `ghp_…` or `gho_…` credentials. It then mounts the entire directory, while leakage scanning checks only the matched PAT. A copied multi-account configuration can therefore expose a full-access token. **Fix:** require an exact scoped-only credential configuration and reject extra credentials before mounting.

3. **MEDIUM — Installed Claude instructions can be missing while binding passes.** [prepare.py:76](/Users/aipalm/Documents/GitHub/devlyn-cli.devlyn.noindex/rp-d7/autoresearch/experiments/rp-d7-prompt-delivery/prepare.py:76) inherits [rp-d6/prepare.py:55](/Users/aipalm/Documents/GitHub/devlyn-cli.devlyn.noindex/rp-d7/autoresearch/experiments/rp-d6-claude-delivery/prepare.py:55), which skips absent `CLAUDE.md` and ultimately requires only `AGENTS.md`. Its import fallback also accepts any occurrence of `@AGENTS.md`. **Fix:** require the Claude entrypoint and validate either its exact managed block or a valid import of the verified `AGENTS.md`; cover missing-file and invalid-import cases.

4. **MEDIUM — Count prerequisites override the frozen classification order.** [grading.py:38](/Users/aipalm/Documents/GitHub/devlyn-cli.devlyn.noindex/rp-d7/autoresearch/experiments/rp-d7-prompt-delivery/grading.py:38): Unknown commit/PR counts return an unset class before checking established quality failures. DESIGN makes quality the first match without those prerequisites; positive publication evidence can also establish `other` without both counts. **Fix:** evaluate quality first, then apply each remaining branch’s specific prerequisites. Update the contrary tests and README statement.

5. **MEDIUM — Unresolved false-completion reviews cannot produce the specified INCONCLUSIVE result.** [grading.py:190](/Users/aipalm/Documents/GitHub/devlyn-cli.devlyn.noindex/rp-d7/autoresearch/experiments/rp-d7-prompt-delivery/grading.py:190): A review leaving `false_completion.value=None` raises instead of preserving the uncertainty required by DESIGN’s first decision rule. **Fix:** accept an unresolved value, retain any established mechanical finding, and let the ordered decision return INCONCLUSIVE.

6. **MEDIUM — Prediction can be marked supported with unknown remaining outcomes.** [summarize.py:78](/Users/aipalm/Documents/GitHub/devlyn-cli.devlyn.noindex/rp-d7/autoresearch/experiments/rp-d7-prompt-delivery/summarize.py:78): One agreed tag-1 skip plus three undispatched/unclassified slots produces `every_skip_includes_1=True` and `supported=True`.
