`--limit 0` now returns 0, and leaving `--limit` out still gives 10. The change is merged to `main` as PR #1 (https://github.com/fysoul17/rpd6-20261018a-m07/pull/1).

**What I changed**
- `src/limitcli/__init__.py`: the cause was `return args.limit or 10`. In Python 0 counts as false, so an explicit 0 was swapped for the default. The default of 10 is now set on the argument itself (`default=10`) and the function returns the parsed value unchanged. The `is not None` check was only needed for the old approach, so I removed it. The nonnegative check is still there.
- `tests/test_regression.py` (new): checks that `--limit 0` and `--limit=0` return 0, that an omitted limit returns 10, and that a missing value, an unknown argument and `-5` all exit with code 2.

**What I verified**
