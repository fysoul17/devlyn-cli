I implemented `slugify`, added the regression test, and merged it to `main` through PR #1 (https://github.com/fysoul17/rpd6-20261018a-smoke-claude/pull/1), following the project's default PR-and-merge delivery. The public check passes: 15 tests.

**What I changed** (only the two allowed files)
- `src/slugtools/__init__.py`: `slugify` raises `TypeError` if the input isn't a string. Otherwise it replaces each run of characters that aren't ASCII letters or digits with one hyphen, strips hyphens from both ends, then lowercases. Empty or separator-only text gives `""`.
  - It lowercases last on purpose. Python's `lower()` turns some non-ASCII characters into ASCII letters (the Kelvin sign `K` becomes `k`), so lowercasing first would let them into the slug. A short comment in the code explains this.
- `tests/test_regression.py` (new): covers runs of mixed separators, leading/trailing hyphens, digits, `_` and `.`, non-ASCII input (`Café` → `caf`, the Kelvin-sign case), empty and separator-only input, and `TypeError` for `None`, `42`, `b"bytes"` and `["a"]`.
