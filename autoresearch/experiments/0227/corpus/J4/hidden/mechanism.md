# J4 mechanism record

- **Family:** cross-field consistency.
- **Mandatory clause:** “When the remeasured entry individually fits the configured size limits but the resulting total would exceed a nonzero `maxSize`, the same-value update must evict least-recently-used entries until the total fits, retaining the updated entry as most recently used. Each evicted entry must receive the existing eviction disposal behavior.”
- **Trigger:** An existing ordinary value is passed again with a larger accepted size. Its new size fits individually, but the aggregate with other entries exceeds `maxSize`.
- **Causal code path:** In `src/index.ts`, private `#set` computes the size and moves the existing entry to the tail, then reaches the `v === oldVal && !isBF` update branch. The reference removes the old indexed size and reuses `#addItemSize`, whose loop enforces `#maxSize` by calling `#evict(true)`. The twin replaces only those helper calls with direct indexed/aggregate size assignments and corresponding status updates, bypassing the eviction loop.
- **Incorrect behavior:** Indexed sizes, their sum, and status agree with each other, but the total violates the cache's capacity. Older entries remain resident and their required eviction disposal notifications do not occur.
- **Executable witness:** `J4-H6` in `hidden/oracle.md`: maxSize 10; insert `a`, `b`, `c` at size 3 each; reset `a` to the identical object at size 8. The reference retains only `a`, total 8; the twin retains all entries, total 14.
- **Near-miss exclusions:** Failure to remeasure the entry at all is a different defect. Incorrect size source precedence, stale `info`/`dump` fields with an otherwise enforced limit, incorrect TTL refresh, reporting `'replace'` instead of `'update'`, replacement disposal of the unchanged value, missing validation, and capacity bugs in insertion/different-value replacement or background fetch are different mechanisms. Callback assertions in the witness observe the consequences of the missing eviction; they do not specify an independent callback defect.
- **Public-check separation:** New public cases exercise changed-size accounting, status, identity, ordering, TTL, and validation while their accepted totals remain within budget. Existing tests exercise ordinary helper-driven eviction. Both patches change the same two files and share the same tests; only the identical-value resize capacity mechanism differs.
