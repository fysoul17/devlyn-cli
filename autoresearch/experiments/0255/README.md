# 0255 — Prospective native receipt runner

0254 established a standalone native receipt auditor. This new runner connects
that accounting boundary to the inherited capture and evaluation pipeline for
Claude solo arms A/B/S. It leaves every historical runner and result unchanged.
This is an offline-tested integration; it has not yet run a live owner or admitted
a new efficacy study. 0252 remains closed with UNKNOWN whole cost.

Subclassing 0253 retains local native body capture, 0251 fixed authentication,
0247 startup/capture parsing, and 0249 evaluator routing. The frozen 0238 run
method directly calls its accounting module, so the new Claude branch explicitly
copies that short orchestration boundary. It replaces the numeric source and
accounting check, preserving the effective amended peer policy and delivery
functions from the inherited method. Codex delegates directly to inherited run.
No module global or old guard is patched to force a pass.

Expected model and effort come from the frozen task route; the account hash
comes from frozen runtime metadata. The exact digest returned by the existing
post-teardown seal is passed to unchanged 0254. Both new runner and auditor are
included in prospective input bindings. Complete receipt accounting permits
source/delivery checking only after the independent identity, peer, teardown,
seal, catalog, quota and unchanged-input gates pass.

The admitted Claude scope is one owner and same-model first-level foreground,
noninteractive native children. H/P refuse before dispatch. Foreign native
carriers are rejected from both sealed inventory and actual files, including
malformed Codex records that the legacy parser cannot identify. Parsed extra
sessions, dispatch attempts, unreadable captures and inventory gaps also refuse.
The existing CLI and amended helper recognizers inspect assistant tool inputs
in stdout, owner/child transcripts and terminal response bodies. A recognized
independent launch without a surviving receipt stays UNKNOWN. This is bounded
recognition of observed native evidence, not an interpreter for arbitrary hidden
shell programs. Quoted helper examples remain non-dispatches.

`native-receipts.json` retains the 0254 accounting observations. `usage.json`
records COMPLETE totals only if accounting and scope are complete. Scope parsing,
peer coverage, teardown and seal failures keep whole totals null/UNKNOWN; no
partial observation is presented as a certified lower bound. Once valid cost is
established, later source/delivery failures retain it. Product failure and
adjudication keep their inherited classifications; accounting MATCH alone never
establishes product success or provider billing.

The entry point takes an already registered runtime and cell identity:

```sh
python3 -B autoresearch/experiments/0255/runner.py <runtime.json> <cell-name> <task-id> <arm> <config>
python3 -B -m unittest discover -s autoresearch/experiments/0255 -p test_runner.py -v
```

A future operational run needs its own frozen registration, inputs, runtime and
current fixed-auth snapshot. This change creates none. Existing cell outputs
are not overwritten, and no closed study is restarted by this entry point.

The [design](results/design-r0.md) and [owner contract](results/owner-contract-r0.md)
precede acceptance. [Verification](results/verification.json) binds exact sources,
independent review and synthetic integration checks. Tests exercise real receipt,
policy and catalog code while replacing external execution and product-check
boundaries. The full synthetic Codex orchestration test preserves routing and
outcome behavior; it mocks old trace-accounting output and does not claim a new
Codex parser test. The unchanged 0253 capture supplies a read-only compatibility
control: 49,313 processed input and 468 output, not a fresh native observation.

Original failures are retained: user prompt strings initially broke the launch
scan; scope errors could lose receipt observations; body-only helper dispatch and
malformed foreign carriers could be missed. The repairs and focused regressions
close those observed gaps (**No workaround**, **Production ready**). Keeping one
explicit new boundary, immutable old studies and no live comparison follows
**No overengineering** and **No guesswork**. Minimal solo stays first, pair only
when earned, ideate deferred.
