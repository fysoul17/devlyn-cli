# Ship bar

A developer brought this as done; would you ship it as is?

Send back if something requested is missing on screen; it is hidden or hard to find on a narrow window or phone; anything is broken, overlapping, cut off, oddly line-broken or awkwardly laid out; or it departs from the request's intent. Otherwise ship; minor taste differences ship.

Every defect names the capture it is visible in. A target state the request names (a width, platform, error state or journey step) with no labelled capture is a send-back; name the missing target in that defect.
